# Visual check

Apply the latest files first:

```bash
omarchy theme set linga-bhairavi
```

Then inspect these surfaces:

1. `Super + Ctrl + Space` — cycle all wallpaper choices in the image picker.
2. `Super + Space` — check launcher borders, selection, and scrim.
3. Click Wi-Fi, Bluetooth, audio, or power — check popup controls and tooltips.
4. `omarchy notification send "Linga Bhairavi" "Notification palette check"`
5. `omarchy dev ui preview` — inspect buttons, focus, selected states, forms, and panels.
6. `omarchy dev theme preview linga-bhairavi` — inspect terminal ANSI colors.
7. `Super + Ctrl + L` — inspect the real lock screen; unlock normally to return.
8. If the companion widget is installed, click the lotus in the right-side
   status cluster — inspect the Stuti panel and Sounds of Isha link.
